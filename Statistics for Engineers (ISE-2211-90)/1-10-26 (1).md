variability: successive observations of a system do not produce the same results!
random variable: exhibits variability
X = µ + c
X = random variable
µ = mean or the expected value
c = variability

**Census**: population is observed 
**Sample**: selected from population
**Statistical inference**: reasoning that sample data applies to population

*TYPES OF STUDIES*
a) **Retrospective**: based on historical data; no control over the way data was collected
b) **Observational**: observe process, record quantities of interest, disturbing as little as possible
c) **Designed Experiment**: Engineer makes deliberate changes to control variables, makes *Inferences* about relationships between observed changes and control variables, only way to determine cause and effect

*MODELS*
ex. Ohms Law for ideal resistor: 
I = E / R
I = current
E = voltage
R = resistance

**Mechanical Model**: built from knowledge of physical mechanism of resistance... actual measurements would exhibit variability
**Empirical Model**: fits measured data to function

**Probability**: helps to quantify risks in statistical inference
