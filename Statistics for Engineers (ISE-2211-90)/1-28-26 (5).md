Discrete Random Variables
random variable: each outcome in the sample space of a random experiment is a real number
denoted by an uppercase variable

**discrete random variable:** finite or countably infinite range of real numbers 
**probability distribution:** describes probabilities associated with possible values of X
can be an equation
for discrete, often a list of possible outcomes and associated probabilities 

Three cell phone cameras tested for flash recharge time; it is known that they pass 80% of the time, write a probability distribution for three independent camera passing/failing

first: determine the sample space of the experiment
lets let
p: pass
f: fail
ppp fff pfp  etc.
this is basically a factorial experiment with 2^k outcomes, where k=3 cameras either pass or fail
2^3 = 8
![[Pasted image 20260129133701.png]]

now we can determine probabilities
let X represent the # of passing cameras
because theyre independent, we use multiplication rule
P {ppp} = .8 x .8 x .8 = .512 or 51.2% is the probability of all 3 cameras passing!
P {ppf} = .8 x .8 x (1-.8) = .128 or 12.8%
P {pfp} = .8 x .2 x .8 = .128 or 12.8%
P { pff} = .8 x .2 x .2 = .032 or 3.2%
P {fff} = .02 x .02 x .02 = .008 or .8%

this chart is NOT a probability distro
by definition, that is a list of probabilities associated with values of X
there are only 4 cases
{0 1 2 3}
**P (0) = p {fff} = .8%**
**P(1) = p {pff fpf ffp} = .032 x 3 = .096**
**P(2) = .128 x 3 = .384 or 38.4%**
**P(3) = P {ppp} = 51.2%**
this is a true probability distro
should add up to 100%
