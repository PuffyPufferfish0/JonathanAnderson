if events A & B are mutually exclusive: P (A ∩ B) = ∅
P(A ∪ B) = P(A) + P(B)

Conditional probability:
outcome of an event depends on the outcome of some other event
P(B|<sub> A</sub>) "The probability of B, given A"
P(B|<sub>A</sub>) = P( A ∩ B) /P(A) 
*Total probability rule:* P(B) = P(B ∩ A) + P(B ∩ A) 
= P(B|<sub>A</sub>) P(A) + P(B|<sub>A'</sub>)P(A')

exhaustive set or sets:
E<sub>1</sub> ∪ E<sub>2</sub> ∪ E<sub>3</sub> ∪ E<sub>k</sub> = S
" events contain all outcomes"

P(B|<sub>E<sub>1</sub></sub>)P(E<sub>1</sub>) + P(B|<sub>E<sub>2</sub></sub>)P(<sub>E<sub>2</sub></sub>) + ... + P(B|<sub>Ek</sub>)P(<sub>Ek</sub>)
